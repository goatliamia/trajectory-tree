# 工具摘要与报错位置

轨迹树和 Eval 使用同一份 [tool-feedback.mjs](../lib/tool-feedback.mjs)。输入来自会话原始事件，生产路径不读取官方统计页，不要求启用 `dsh-experimental-client-ui-stats`。该可选插件的 rc.2 `stats-fold.ts` / `StatsTable.tsx` 仅作为计量与呈现的对照。

## 操作摘要

| 工具 | 显示 | 依据 |
| --- | --- | --- |
| `write` | 绿色 `+N 行` | 写入参数中的内容行数；空文本为零，末尾换行不多算一行。不是相对磁盘旧文件的 Git diff。 |
| `edit`、可识别替换参数的 `apply_patch` | 绿色增加、红色删除 | 同官方口径比较替换片段；每侧不超过 400 行时做行 LCS，更大片段采用净行数近似并保留标记。 |
| `read` | `N 行` | 完整工具返回的文本行数。 |
| 其他工具 | `N 字符` | 完整文字返回的字符数，与官方口径一致。 |

没有对应参数格式时不拼凑数量。失败或尚无返回的写入显示中性的「计划」或「待返回」，不把请求中的变更量当作已完成修改。绿色／红色只表示增加／删除；工具名保持自己的官方分类色。

计算在事件投影时完成，先于截断原文，不用截断后的预览估算总量。PTC 子调用直接读取原生 dispatch 事件；有子调用的成功 `run_code` 外壳不另作工具操作，失败外壳继续保留已有关系与状态。

轨迹主线仅保留工具名称、调用次数和状态，不在节点下追加字符量、行数或报错位置。行动路径下方的步骤详情、点选结果枝条的抽屉、失败事件中的原始调用，共用 `geist-tool-record.js`：整行摘要作为折叠入口，箭头、工具名、操作对象、计量和耗时组成行头，下一行给出返回或报错摘要。工具名按文字宽度排列，不占固定的宽列；不再把展开链接插入序号与 PTC 元数据之间。

展开内容使用整行宽度，序号、PTC 外层关联和改动入口放在内容顶部。参数与返回在可用宽度超过 760px 时并排，窄抽屉上下排列；JSON 参数适度格式化，终端输出保留空格和原始换行，长行在代码区内横向滚动，避免破坏表格列对齐。PTC 外层程序与内部工具使用相同版式。报错位置与附近代码在该条记录展开后直接显示，不再加一层报错展开入口。

画布在步骤详情展开后按实际剩余高度重新排布。详情与 Eval 的反馈、窗口调用记录共用相同计量与错误位置渲染函数。旧冻结轨迹 Demo 可复用已保存的官方统计快照；新的原生路径直接使用自己的事件投影结果。

## 报错定位

- PowerShell：优先使用已有 CR 静态解析给出的 line、column、错误 ID 与 message；也读取原生 ParserError 报告。不新增解析器，不执行历史命令。
- PTC：区分原生 `run_code` 的语法错误、运行异常和 `ToolCallError`。内部工具仍显示自己的记录与错误位置。
- TypeScript 编译输出、远端 Bash 报告：显示记录明确给出的文件／行列与原因。不会把远端脚本的行号标到外层 PowerShell 上。
- `NativeCommandError` 包装、克隆进度等不因此被画成语法错误。PTC 的 Captured output 不能提供冒充原生堆栈的位置。

记录摘要先给出行列与简短原因，展开该条记录时才生成代码行 DOM，并放在记录信息之前。详情显示报错行及前后最多两行，带行号、浅红背景、具体字符位置和原始原因。列位置用行内标记定位，避免中文或 tab 造成空格插入符错位。每条代码最多显示 220 字符，每次最多三组位置；敏感赋值做遮盖，全部文本经过 HTML 转义。

只有静态解析的原脚本，或运行时打印的代码与该位置原文一致时，才标记调用代码。外部文件、V8 包装／转译后坐标、缺少代码或缺少行号时只展示已记录的位置与原因，不猜映射。静态解析标为「静态语法检查」，不自动升级为根因判定。

## 性能与验证

新增逻辑是有界的文本投影和小段标记，不调用模型，不下载向量模型、语法服务或编辑器。现有 PowerShell 批次上限、输入预算与 2.5 秒时间预算保持不变。页面绘制只复用结果，不在每次切换或悬停时重算 diff 或重新解析。

2026-11-13，在本机冻结样本的 **1,486 条调用**上，六次新增计量投影耗时约 **3.6–6.7 ms**；其中 **352 次**可比较写入／替换的增删计量与官方快照一致。这个读数不包括日志解压、现有解析器启动或浏览器布局，不代表整页加载时间。记录在 `.dsh/tool-feedback-review/benchmark.json`。

[针对性测试](../analyzers/tool-feedback-test.mjs)覆盖末尾换行、大片段近似、失败写入、坐标与源码对应、遮盖与转义、远端与外层区分、PTC 三类反馈、Captured output 排除及子调用去重；同时复核现有代码执行、PowerShell、Eval 统计和宿主自检。
