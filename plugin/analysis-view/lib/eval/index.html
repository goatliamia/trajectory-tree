时间口径

  • 各轮耗时、各步耗时按各自的实录起止求和。模型处理使用 DSH 的步骤统计，含首字延迟和解码。
  • 输出 token 按每轮模型响应上报的 outputTokens 相加，包含中间响应。交叉图以整段会话为参照，仅绘制有轮次起止且已记录的模型响应均上报输出量的轮次。
  • 工具累计耗时按调用发起到结果逐次相加，含观测到的调度和等待，重叠调用分别计时。步内工具覆盖把调用区间裁到所属步骤，重叠部分计一次。
  • 耗时分布的档位含左边界。首档低于 20 ms，末档含 30 s 及以上。
  • 结果覆盖率以全部调用为分母。报错占比以已记录结果的调用为分母。
  • 报错优先按实录中的错误码分类，其余沿用轨迹归类。同参返回指同一轮内同工具、同完整参数的后续非报错返回。
  • 文件前读和读回按有配对写入记录的文件计算，搜索命中单独计数。
