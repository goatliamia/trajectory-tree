项目与范围
按 DSH 工作区登记的会话归类。时间按轮次开始计算，时区为北京时间。起始模型按轮次首个已记录回复的供应方与模型筛选。
正文与工具
正文只取已记录回复里带时间戳的非空白文本。每天有至少 5 轮计时时显示日 P50 和 P90。PTC 展开为实际子调用，独立代码执行和外层报错单列。模型往返以模型收到正式工具返回后开启下一步为准。
用量与同参返回
输出 token 按供应方回报统计。同参匹配复用单会话 Eval 的调用签名和错误分类。返回时间从报错返回算到同轮同参非报错返回。
任务推进
结束状态取 DSH 的轮次结束记录。目标按新建时所在轮次或登记时间纳入，显示快照时最后一个状态。交付取宿主登记，同一个产物可以登记多次。
模型对照
每组区分模型、供应方、推理档位和工具执行方式。文件取证与修改按同一轮的实际文件记录关联。反馈后的动作来自后续模型步骤。显式检查取已返回的常见测试、语法或差异检查命令。
窗口占用对照
模型请求用供应方报告的输入 token 除以同路由的窗口上限。工具调用取发起前的 DSH 窗口占用回放，报错率以有结果的调用为分母。报错类型筛选用于报错率和同参返回率。同参返回取同轮同参的非报错结果。
项目与范围
按会话记录中的工作目录归类。时间筛选按轮次开始计，范围截至所选记录的最近一天。
模型用量
用量按宿主记录的请求或助手消息计。窗口占用要求同一请求有输入量及窗口上限记录。
工具结果
报错率以有结果的调用为分母。同参返回沿用单会话 Eval 的调用配对。耗时采用宿主留下的持续时间或配对区间。
