Open **Trajectory Tree** in a conversation, or enter `/trajectory`. Select a turn to follow tool arguments, results and changed files. Hold a step or a context-change bar to start a diagnosis draft with the selected records.

| What you want to see | Where to open it in DSH |
| --- | --- |
| Timing, usage, tool errors and code execution by turn | **Eval** in the conversation |
| Comparisons across sessions, filtered by project and time | **Eval overview** in the left sidebar |
| What the session currently retains and the text of individual items | **Current context** in the right sidebar, or `/context-map` |
| The turn containing a particular message or tool result | **Conversation search** in the right sidebar. Select a match to open the original turn. |

The context view estimates the size of each visible source. Eval shows the host's recorded input and cache usage separately.
