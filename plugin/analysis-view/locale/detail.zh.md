在会话里打开**轨迹树**，或输入 `/trajectory`。点选一轮可以沿工具调用查看参数、返回结果和改动的文件。长按图中的步骤或上下文增量柱，可以把选中的记录填入诊断草稿。

| 想查看的内容 | 在 DSH 中打开 |
| --- | --- |
| 各轮的耗时、用量、工具报错与代码执行 | 当前会话的**评估** |
| 跨会话比较，按项目和时间筛选 | 左侧栏的 **Eval 总览** |
| 此刻保留了哪些上下文，某个片段里有什么 | 右侧栏的**当前上下文**，或输入 `/context-map` |
| 某句话或工具结果最早出现在哪一轮 | 右侧栏的**对话搜索**，点选命中即可回到原文 |
